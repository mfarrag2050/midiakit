# المواصفات الإلزامية

## 1. المحرك — الحد الأدنى القابل للبيع

- محرك خالص `(template, brand, content, size)`
- تحميل خط العميل ديناميكياً مع انتظار الجاهزية قبل القياس
- صفر قيم مثبتة للهوية
- يعمل في المتصفح وNode بنفس الكود

**اختبار القبول الوحيد:** ثلاثة ملفات `brands/*.json` تُنتج ثلاثة مخرجات مختلفة تماماً بلا لمس كود.

## 2. المخرجات

| النوع | المقاس | الصيغة |
|---|---|---|
| بطاقة X | 1080×1080 | PNG · sRGB · ≤ 3MB |
| بطاقة إنستغرام | 1080×1350 | PNG · sRGB |
| ستوري / ريلز | 1080×1920 | PNG أو MP4 |
| فيديو | 1080×1920 · 30fps | MP4 · H.264 · AAC 128kbps · ≤ 90s |

مواصفات المنصات تتغيّر — تُتحقق وقت البناء وتُوضع في `brandKit.outputs` لا في الكود.

**ثلاثة غير قابلة للتفاوض:**
- `sRGB` صراحةً — وإلا ظهرت ألوان الهوية باهتة على إنستغرام
- المنطقة الآمنة: لا نص في أعلى ~250px أو أسفل ~320px من الستوري (واجهة التطبيق تغطيها)
- **MP4 حقيقي لا WebM** — هذا سبب وجود الرندر على الخادم أصلاً

## 3. القوالب والخطوط

**القوالب:** أربعة تكفي — عاجل · غلاف (نمطان) · ريلز. **لا خامس قبل العميل الرابع.**

**الخطوط:** كتالوج من 7 خطوط عربية مستضافة ذاتياً في `mediakit-assets`، مع خيار رفع خط العميل. الكتالوج يزيل حاجز البداية: العميل يرى عنوانه مرسوماً قبل أن يرفع شيئاً.

## 4. الأداء

- بطاقة: < 3 ثوانٍ (في المتصفح، فورية عملياً)
- فيديو 60 ثانية: < 90 ثانية
- تفاصيل الذروة والالتزام في ملف 08

# استمارة الإعداد

أهم وثيقة تجارية في هذه المرحلة. ملف واحد يوقّعه العميل قبل بدء العمل. **بلا هذه الاستمارة يتحول كل عميل إلى مشروع مفتوح.**

## الهوية
- [ ] **الخط:** اختيار من الكتالوج (7 خطوط عربية مستضافة عندنا) **أو** رفع خطه
- [ ] عند الرفع فقط: ملفات TTF/OTF بثلاثة أوزان + **إقرار خطي بامتلاك ترخيص الاستخدام التجاري الرقمي**
- [ ] الشعار: SVG أو PNG شفاف ≥ 512px

## التحرير
- [ ] نص شارة العاجل («عاجل» / «خبر عاجل» / صيغة أخرى)
- [ ] صيغة المصدر («مصدر لـ…» / «المصدر: …»)
- [ ] الحد الأقصى للكلمات في العنوان
- [ ] **الموسيقى:** لا مكتبة مضمّنة في الإصدار الأول — يرفع العميل موسيقاه المرخّصة أو يستخدم صوت المقاطع الأصلي
- [ ] المقاسات المطلوبة فعلاً
- [ ] اللغات: عربية فقط؟ عربية + إنجليزية؟ + هولندية/فرنسية؟

### التشكيل — العميل يملك القرار، النموذج مساعد لا سلطة

النموذج (`services/diacritizer/`) اقتراح لا مصدر ثقة. **العميل يتحكّم
في التشكيل النهائي بالحرف.** التدفق الملزَم في الواجهة:

1. العميل يكتب العنوان **عارياً** كما اعتاد.
2. يضغط زر **«شكّل»** (اختياري) — تُستدعى الخدمة، يظهر ناتجها في:
3. **حقل نصي قابل للتحرير**، لا في المعاينة مباشرة.
4. يصحّح ما شاء **حرفاً بحرف** (النموذج معدَّل خطئه ~6.6% — يكفي 15
   كلمة لخطأ واحد في المتوسّط).
5. المعاينة تتحدّث مع كل تعديل.
6. النص المشكَّل **المحرَّر** هو ما يُخزَّن ويُصدَّر.

**متطلبات إضافية (المرحلة 4، الواجهة):**
- زرّ **«أزل التشكيل»** — يجرّد كل العلامات بضغطة (regex واحد).
- **حفظ النص المشكَّل مع المشروع** في قاعدة البيانات — لا يُعاد
  التشكيل عند كل فتح، فتضيع تصحيحات العميل.
- **تشكيل جزئي مسموح** — بعض الكلمات مشكّلة وبعضها لا (السلوك الصحفي
  المعتاد: تُشكَّل الكلمة الملتبسة فقط). المحرك يتعامل معه بلا خلل —
  مُثبَت آلياً في `packages/engine/src/text/diacritics-interaction.
  test.ts` (كشيدة على العارية فقط، ارتفاع سطر يعكس المشكّلة).
- **لوحة مفاتيح مساعدة** — أزرار للحركات الثمانية (فتحة · ضمة · كسرة
  · سكون · شدة · تنوين ×3) لتسهيل التصحيح على من لا يعرف اختصارات
  لوحة المفاتيح العربية.

**نموذج البيانات:** `content.headline` يحمل النص **كما حرّره العميل**
— حرفاً بحرف، بما فيه التشكيل الجزئي. لا حقل منفصل «مشكّل/غير مشكّل».
النص هو النص.

# العميل الأول

**العميل مقيم في بلجيكا، لكن المشروع خليجي ولا علاقة له بالاتحاد الأوروبي.** لا تُفرض قيود امتثال أوروبية على البناء. موقع إقامة الشخص لا يحدد الاختصاص، بل موقع الكيان والجمهور.

## الأثر على القرارات

| البند | القرار |
|---|---|
| موقع الخادم | حسب أداء الجمهور الخليجي — فرانكفورت أو البحرين أو دبي. اختيار تقني لا قانوني |
| DPA وسياسات GDPR | غير مطلوبة الآن |
| الفوترة | حسب بلد تسجيل الكيان — راجع محاسباً |
| اللغات | عربية أولاً؛ الإنجليزية عند الحاجة |

## ما يبقى مطلوباً بصرف النظر

هذه ليست امتثالاً بل ممارسة سليمة تُطلب في أي عقد جاد:

- [ ] **BiDi** — عنوان عربي بكلمة لاتينية يظهر بترتيب صحيح
- [ ] خيار الأرقام العربية (١٢٣) أو اللاتينية (123)
- [ ] إقرار ترخيص الخطوط من العميل
- [ ] مسؤولية حقوق الصور على العميل — بند في العقد
- [ ] سياسة احتفاظ واضحة: كم تبقى الملفات المرفوعة
- [ ] تصدير بيانات العميل عند الانسحاب
- [ ] نسخ احتياطي واستعادة مُختبرة

## لماذا BiDi مطلوب رغم ذلك

ليس بسبب بلجيكا. المحرّك اليوم يفترض RTL خالصاً، وأي عنوان إخباري عربي يحتوي اسماً لاتينياً — علامة تجارية، منظمة، وسم — سيظهر بترتيب مقلوب. هذا يحدث في الخليج كما في أوروبا.

**التنفيذ:** تقسيم النص إلى مقاطع حسب الاتجاه، وعكس ترتيب المقاطع اللاتينية داخل السياق العربي. ليس معقّداً، لكنه يجب أن يسبق أول عرض حي.

```jsonc
"bidi": { "enabled": true, "numerals": "arabic" }  // arabic | latin
```
