# demo — لقطات مقارنة قبل/بعد الكسر الدلالي

العناوين مختارة من مسح 265 عنوان RSS. كل واحد يُظهر أثر قاعدة
مختلفة — ما لا تفعله Canva ولا أي أداة تصميم عربية.

التمييز البصري بين الملفَين: `-before.png` = enabled=false،
`-after.png` = enabled=true + ExtendedLexicon (places · entities · titles).

## demo 1 — particle

**العنوان الكامل:**
> الاتحاد الأوروبي يحذّر صربيا من تكريم مجرم الحرب ملاديتش

- **المصدر:** aawsat
- **القاعدة التي تدخّلت:** حرف جر (BREAK_INFINITY)
- **السبب:** الكسر بعد «من» — حرف جر ملازم لمجروره — يُمنع دلالياً.

**قبل** (fs=80, بلا الكسر الدلالي):
```
الاتـــحاد الـــأوروبي يحذّر صربـــيا من
تكريم مجرم الحرب ملاديتش
```

**بعد** (fs=80, مع الكسر الدلالي):
```
الاتـــحاد الـــأوروبي يحذّر صربـــيا
من تكريم مجرم الحرب ملاديتش
```

**الملفَان:** `demo/demo-1-before.png` · `demo/demo-1-after.png`

## demo 2 — place

**العنوان الكامل:**
> سوريا.. بدء ضخ الغاز من حقل كونيكو في دير الزور لدعم قطاع الكهرباء

- **المصدر:** aljazeera
- **القاعدة التي تدخّلت:** اسم مركّب في places.json (BREAK_STRONG)
- **السبب:** «دير الزور» زوج معروف من GeoNames — لا يُفصل بين طوكنَيه.

**قبل** (fs=80, بلا الكسر الدلالي):
```
سوريـــا.. بـــدء ضخ الغـــاز
من حـــقل كونـــيكو في دير
الزور لدعم قطاع الكهرباء
```

**بعد** (fs=80, مع الكسر الدلالي):
```
سوريـــا.. بـــدء ضخ الغـــاز
من حــقل كونــيكو في دير الـزور
لدعم قطاع الكهرباء
```

**الملفَان:** `demo/demo-2-before.png` · `demo/demo-2-after.png`

## demo 3 — title

**العنوان الكامل:**
> تجديد عقد حسام حسن مدرب منتخب مصر حتى 2030

- **المصدر:** aawsat
- **القاعدة التي تدخّلت:** لقب في titles.json (BREAK_STRONG)
- **السبب:** «مدرب» لقب مهني — رابطة قوية مع الاسم/المنصب الذي يليه.

**قبل** (fs=80, بلا الكسر الدلالي):
```
تجــديد عـقد حسـام حـسن مـدرب
منتخب مصر حتى 2030
```

**بعد** (fs=80, مع الكسر الدلالي):
```
تجـــديد عـــقد حســـام حـــسن
مدرب منتخب مصر حتى 2030
```

**الملفَان:** `demo/demo-3-before.png` · `demo/demo-3-after.png`
